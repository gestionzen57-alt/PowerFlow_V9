# docs/reports/

Destination des rapports générés par les outils de calibration, replay et vérification de
fraîcheur documentaire (`tools/doc_sync.py`, `scripts/v9_calibration.py --export`, etc.).

Contenu généré, non versionné par défaut sauf rapport jugé significatif à conserver comme
référence (dans ce cas, le committer explicitement avec un nom daté, ex.
`doc_freshness_2026-07-05.md`).
