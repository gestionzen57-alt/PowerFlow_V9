## REFORMULATION DE LA DESCRIPTION DE SØN

### La séquence complète (ce que Søn a décrit)

```
PHASE 1 — LE H1 EMBÔÎTE LE PAS (anticipation)
   Le H1 croise AVANT le H4 : la force GBP commence à décliner et la force
   USD à monter sur H1, pendant que H4 est encore dans l'ancienne phase.
   → Le H1 est l'ANTICIPATEUR du changement de phase.

PHASE 2 — LE H4 CONFIRME LE CHANGEMENT DE PHASE (signal majeur)
   Le H4 croise : GBP passe du haut en bas, USD passe du bas en haut.
   → Le croisement H4 = CHANGEMENT DE PHASE CONFIRMÉ (le régime change).

PHASE 3 — LA STRATÉGIE DU LENDEMAIN (exploitation)
   Une fois la phase changée (GBP faible, USD fort) :
   - VENDRE tous les extrêmes HAUTS de la force GBP (chaque pic de GBP
     est une opportunité de vente — la force GBP ne peut plus pousser)
   - ACHETER tous les extrêmes BAS de la force USD (chaque creux de USD
     est une opportunité d'achat — la force USD va continuer)
   → On trade la NOUVELLE phase, pas l'ancienne.

PHASE 4 — LE POINT DE RETOURNEMENT (l'antagonisme)
   Quand les 2 forces sont ANTAGONISTES (GBP extrême haut + USD extrême
   bas, ou l'inverse), c'est un POINT DE RETOURNEMENT POSSIBLE.
   → La confirmation vient du croisement de force sur un TF < (M15/M5/1min).
```
