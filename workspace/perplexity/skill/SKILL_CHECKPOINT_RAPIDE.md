# Skill : Checkpoint rapide PowerFlow

## Usage
Quand une session Claude Code ou une observation live produit un résultat,
produis un checkpoint structuré en 20 lignes max.

## Format attendu
Date / Branche / Commit
Phase concernée
Ce qui a changé
Ce qui est acquis
Ce qui reste ouvert
Risques identifiés
Prochaine action

## Règles
- Toujours référencer un commit ou une branche réelle
- Toujours dater
- Jamais de conclusion floue
- Toujours lister au moins 1 "prochaine action" concrète
